# Asset Meta Files
Asset meta files are editor-managed files that contain information about assets.
## What do they contain?
- All the Cooked Assets' UUIDs and their types
## Structure
Example structure:
```json
{
  "cooked_assets" : [
    {
      "uuid" : "123456789",
      "type" : 0
    },
    {
      "uuid" : "987654321",
      "type" : 7
    }
  ]
}
```
